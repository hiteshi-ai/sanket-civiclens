1. THREE ROLE-BASED PORTALS
==================================================

The application must have three roles:

CITIZEN
MUNICIPAL
ADMIN

Create a proper login screen before accessing any portal.

After login, route the user to the appropriate portal.

Citizen:
- Can submit civic reports
- Can view their own submitted reports/status
- Cannot access municipal dashboard
- Cannot access admin functions

Municipal:
- Can access municipal dashboard
- Can view incidents/reports allowed for municipal operations
- Can inspect scores/evidence
- Cannot access admin management functions

Admin:
- Can access administrative dashboard
- Can inspect users/roles
- Can inspect audit information
- Can inspect system/data-source status
- Can access the broader system
