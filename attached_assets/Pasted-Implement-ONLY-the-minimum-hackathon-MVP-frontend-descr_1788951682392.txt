==================================================
VIEW 1 — CITIZEN REPORT
==================================================

Create a Citizen Report page.

It must allow:

1. Select/take a photo.
2. Preview the photo.
3. Capture browser GPS using navigator.geolocation.
4. Display latitude, longitude and accuracy.
5. Select a civic issue category.
6. Enter an optional description.
7. Generate a unique idempotency key.
8. Submit to:

POST /api/v1/sync/report

Use the EXISTING backend request contract:

- idempotency_key
- category
- photo_base64
- latitude
- longitude
- accuracy_meters
- location_source
- description
- client_timestamp

Do not invent fields.

After successful submission:

- display report ID
- display incident ID/number if returned
- display citizen-selected category
- display AI prediction separately if returned
- display AI confidence if returned
- display Civic Confidence
- display Civic Risk
- display Priority

If a value is unavailable, display:
"Data unavailable"

Do NOT invent fallback numbers.

VIEW 2 — MUNICIPAL DASHBOARD

GET /api/v1/analytics/overview
